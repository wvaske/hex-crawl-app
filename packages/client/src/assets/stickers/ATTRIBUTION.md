# Sticker icon attribution

The map-marker stickers in this directory are derived from [game-icons.net](https://game-icons.net) ([source repository](https://github.com/game-icons/icons)) and are used under the [Creative Commons Attribution 3.0 Unported licence (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

**Modifications:** each file was reduced to its foreground path data, the opaque background rectangle was removed, and the hard-coded white fill was replaced with `fill="currentColor"` so the icon takes its colour from the surrounding UI.

No assets from D&D Beyond (or any other commercial VTT) are used here; that product is a design inspiration only.

## Authors

Icons made by [Caro Asercion](https://game-icons.net), [Delapouite](https://delapouite.com), [Lorc](https://lorcblog.blogspot.com), [Sbed](https://opengameart.org/content/95-game-icons), [Skoll](https://game-icons.net) — all via [game-icons.net](https://game-icons.net).
